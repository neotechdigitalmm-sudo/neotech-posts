# ნეოტექის მარკეტინგული სააგენტო

საიტი: https://neotechdigitalmm-sudo.github.io/neotech-posts/

## რა არის აქ
- `index.html`, `app.js`, `store.js`: საიტი (დიზაინი და მუშაობა).
- `config.js`: Firebase-ის მისამართი (პროექტი `neotech-marketing`) და ბრენდის პარამეტრები (BRAND).
- `tools/add_post.py`: გამზადებული პოსტის დამატება და „გამოქვეყნდა“ ლინკებით.
- `CLAUDE.md`: სრული ინსტრუქცია Claude-სთვის. `ინსტრუქცია_სრული.md`: სრული ინსტრუქცია შენთვის.
- `firestore.rules`: ბაზის დაცვის წესები. შეცვლის მერე Firebase-ში ჩასვით: Firestore, Rules, Publish.
- `posts.json` და `posts/`: ჩვენი გამზადებული პოსტები (ტექსტი, სურათები, ლინკები).
- `fonts/`, `raw_logo.png`: შრიფტი და ლოგო.
